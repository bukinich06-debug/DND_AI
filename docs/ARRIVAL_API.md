# Описание прибытия игрока в локацию

## Текущий подход

Для описания окружения при прибытии в новое место используйте **прямой вызов Master** через `POST /api/master`.

### API: `POST /api/master`

**Запрос**

```json
{
  "campaignId": "string",
  "playerId": "string",
  "messages": [
    {
      "role": "user",
      "content": "Осматриваюсь. Где я и что вижу вокруг?"
    }
  ]
}
```

**Ответ (200 OK)**

```json
{
  "verdict": "success" | "partial" | "check",
  "say": "string",
  "check": null | { "skill": "...", "dc": 15 },
  "toolCalls": []
}
```

- `say` — текст от лица мастера, описание окружения
- `verdict` — результат обработки запроса
- `check` — если Master просит проверку навыка (редко при простом осмотре)
- `toolCalls` — лог использованных tools (get_player_location, search_location_items, список NPC)

### Использование в чате

Добавьте `say` в массив сообщений как ответ ассистента:

```typescript
messages.push({
  role: 'assistant',
  content: response.say
});
```

## Когда вызывать

### ✅ Вызывать обязательно

1. После `PATCH /api/location/player` (смена места на карте)
2. После `POST /api/location/player/advance` **когда `travel` стал `null`** (прибытие)

### ❌ Не вызывать

1. Во время путешествия (`travel !== null` после `advance`) — игрок ещё в пути
2. Когда игрок просто ходит по одной локации (например, по комнатам здания)
3. Во время хода игрока (`POST /api/turn`) — там Master сам описывает окружение по запросу

## Отличие от `/api/turn`

| | `/api/turn` | `/api/master` (прибытие) |
|---|---|---|
| Когда | Игрок что-то делает или говорит | Игрок прибыл в новое место |
| Планировщик | Да — может роутить к NPC или Master | Нет — прямой вызов Master |
| Контекст | История диалога, действие игрока | Сообщение игрока с запросом осмотра |
| Ответ | Может быть проверка навыка, действия NPC | Master описывает место с помощью tools |

`/api/turn` используется для **хода игрока** (диалог, действие, осмотр по запросу).

`/api/master` — для **прямого обращения к Master** (описание прибытия, осмотр места без планировщика).

---

## Резюме для UI-команды

1. **Обязательный вызов:** после смены локации игрока вызовите `POST /api/master { campaignId, playerId, messages: [{ role: "user", content: "Осматриваюсь..." }] }`.
2. **Добавьте в чат:** ответ `say` как `{ role: 'assistant', content: ... }`.
3. **Не путайте с turn:** `/api/turn` — для действий игрока; `/api/master` — для прямого вызова Master без планировщика.

## История изменений

- **Ранее:** `/api/location/describe` — удалён; специальный API для arrival
- **Сейчас:** `/api/master` — универсальный прямой вызов Master с tools
